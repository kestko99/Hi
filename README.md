# ChangeNOW Clone - Crypto Exchange Interface

A pixel-perfect 1:1 recreation of the ChangeNOW crypto exchange interface built with modern web technologies.

## Features

- 🎨 Exact replica of the ChangeNOW mobile interface
- 💱 Real-time cryptocurrency exchange calculations
- 🌓 Dark theme with glass morphism effects
- 📱 Mobile-first responsive design
- ⚡ Built with Next.js 14 and TypeScript
- 🎯 Tailwind CSS for pixel-perfect styling

## Tech Stack

- **Framework:** Next.js 14
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **UI Components:** Headless UI
- **Icons:** Lucide React

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) in your browser

## Project Structure

```
src/
├── app/              # Next.js app directory
├── components/       # React components
├── types/           # TypeScript type definitions
├── utils/           # Utility functions and data
└── hooks/           # Custom React hooks
```

## Components

- **Header:** Status bar and navigation
- **WarningBanner:** Risk disclosure banner
- **ExchangeWidget:** Main crypto exchange form
- **CryptoSelector:** Dropdown for selecting cryptocurrencies
- **Footer:** Cookie notice and additional options

## Features Implemented

- ✅ Live time display in status bar
